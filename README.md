# flowstate-mas

**FlowState** is a multi-agent line-down recovery system for automotive Tier-1 supplier plants. When an inbound part is late or a machine goes down, it traces the impact, generates recovery options, verifies them with a constraint solver, costs them against freight and OEM contract terms, and hands the plant materials manager a ranked plan to approve and execute.

Built as a project for Mahesh Yadav's AI PM course (Maven).
